Run a small current-based network for **200 ms**, learning from its spikes while
`simulate` advances the dynamics. The example exercises additive and weight-dependent
pair STDP, triplet STDP, homeostatic inhibitory STDP, reward-modulated STDP and a
custom Hebbian rule. Each rule starts a separate trajectory with weights of 0.3 nA.

![Two spike input channels connect to two current-based LIF cells through an excitatory projection named drive.](/plasticity/network.png)

The diagram shows the base circuit. The inhibitory variant changes `drive` to
an inhibitory projection and adds fixed excitation of 0.8 nA per connection.
The reward variant adds a continuous scalar reward input. All variants use a
1 ms timestep, batch size one and dense, unshared plastic weights.

Plasticity is an explicit option on `simulate`; it is separate from gradient
`train` and fixed-weight prepared streaming. The
[plasticity API reference](/api/sim#online-plasticity-simulate-only) defines the
rule parameters, timing conventions, equations and literature sources.

## 2. Choose built-in rules

The example imports rules from `snnlab.plasticity` and builds a separate
`Plasticity(rules={"drive": rule})` request for each one. Parameters below are
illustrative choices for this circuit, not universal defaults or fitted
experimental parameter sets.

```python
{{RULES}}
```

1. **Pair STDP** accumulates exponentially decaying pre/post traces and applies
   additive timing-based updates. Its weight-dependent variant scales each
   update by the normalized distance to the relevant weight bound.
2. **Triplet STDP** adds slow pre/post traces to the pair terms. Both pair and
   triplet contributions remain subject to the same weight bounds.
3. **Inhibitory STDP** adapts inhibitory magnitudes using a target-rate parameter.
   The extra fixed excitatory drive lets the postsynaptic cells fire while their
   incoming inhibition changes.
4. **Reward-modulated STDP** stores pair increments in an eligibility trace and
   converts them to weight changes using the signed reward input. Zero reward
   allows eligibility to decay without changing weights.

## 4. Advance consecutive input windows

Input channel 0 spikes every 5 ms, starting at 0 ms. Channel 1 spikes every 7 ms,
starting at 2 ms. Reward is +1 from 60 to 100 ms, −1 from 140 to 180 ms, and zero
elsewhere; both intervals exclude their ending timestamp. These are held scalar
samples, not instantaneous reward impulses.


Each call delivers ten numerical steps. Passing the previous runtime state
carries membrane voltage, synaptic currents, delayed events, plastic weights
and learning traces into the next call.

```python

```

All projections transmit using their existing weights before the learning phase
at the end of a timestep. Built-ins read the actual delayed presynaptic arrivals
and emitted postsynaptic spikes. Weight updates affect subsequent transmission.
Public plastic simulations use eager execution, highest precision and no CUDA
graph replay. Repeated `simulate` calls here illustrate continuation; they are
not a prepared streaming session or a performance benchmark.

Each array file contains:

1. `weights`: shape `(21, 2, 2)`, sampled initially and after each 10 ms call,
   with axes `(sample, source, target)` and values in nA.
2. `time_ms`: the 21 weight-sampling times from 0 through 200 ms.
3. `input_spikes` and `spikes`: shape `(200, 1, 2)`, with axes `(step, batch, cell)`.
   Their rows are 1 ms simulation slots, not the 10 ms weight-sampling times.
4. `reward`: shape `(200, 1, 1)` for the reward rule and an empty array otherwise.

The local run also writes network diagrams, `<rule>-rule.json` files and
`<rule>-state/` directories. State directories contain both `manifest.json`
and `tensors.npz`; preserve both for continuation. The JSON configuration alone
does not contain learned weights or dynamic state.

## 6. Restore a learned trajectory

After running the script, restore the reward rule and continue for another
10 ms. Run this from the script's directory, with its `example.py` importable:

```python
import json
from pathlib import Path

import torch

from example import make_graph
from snnlab import sim
from snnlab.plasticity import Plasticity

learning = Plasticity.from_json(
    json.loads(Path("results/reward-modulated-rule.json").read_text()),
)
state = sim.load_runtime_state("results/reward-modulated-state")
continued = sim.simulate(
    graph=make_graph(reward=True).graph,
    device="cpu",
    plasticity=learning,
    runtime_state=state,
    input_bindings=[
        sim.DenseArrayBinding("events", torch.zeros(10, 1, 2)),
        sim.DenseArrayBinding("reward", torch.ones(10, 1, 1)),
    ],
)
```

The result reaches 210 completed steps. Changing the learning rule or omitting
it rejects continuation; keep the same rule configuration and graph. The
inhibitory variant's extra excitatory weights remain static and must also be
restored consistently if you change their initialization or load a checkpoint.
