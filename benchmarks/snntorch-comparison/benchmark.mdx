---
title: "MNIST: SNNLab vs snnTorch"
description: Training curves and execution timings for matched MNIST classifiers on NVIDIA L4 GPUs.
---

We compare SNNLab’s native `snnlab.sim.train()` workflow with snnTorch on MNIST.
Both use **784 inputs → 1,000 spiking hidden neurons → 10 spiking outputs**,
shared initial weights and data order, and matched current-based neuron dynamics.
They train on **6,000 images for 20 epochs**, with batch size 128, 25 simulation
steps per image and Adam at learning rate 0.0005. Evaluation uses all **10,000 test
images**. These are single-seed results on NVIDIA L4 GPUs.

![Training loss and test accuracy over 20 epochs. Black solid lines show snnTorch; red dashed lines show SNNLab.](/snntorch-comparison/mnist-30fabde19a1a7aa1/training-curves.png)

**Training curves.** Left: training-set cross-entropy summed over the 25 simulation
steps. Right: test accuracy using output spike counts. Each point evaluates fixed
weights after an epoch; lines are unsmoothed. Black solid lines show snnTorch and
red dashed lines show SNNLab. The accuracy gap means these runs do not establish
training equivalence.

**Network and training configuration**

| Setting | snnTorch | SNNLab |
| --- | --- | --- |
| Architecture | 784 → 1,000 → 10, fully connected | Same |
| Neurons | `snn.Synaptic` in hidden and output layers | Custom current-based neurons matching `snn.Synaptic` |
| Synaptic decay per step, alpha | 0.9, fixed | 0.9, fixed; exponential-current synapses |
| Membrane decay per step, beta | 0.95, fixed | 0.95, fixed |
| Spike threshold | 1, normalized units | 1 mV, matching normalized threshold |
| Reset | Delayed subtractive; reset decision detached from gradients | Same |
| Surrogate gradient | Default ATan, slope parameter 2 | Matched ATan derivative |
| Biases | Trainable bias in each `Linear` layer | Equivalent trainable constant-input weights |
| Trainable parameters | 795,010 weights and biases | Same |
| Initialization | Seeded PyTorch `Linear` initialization | Identical copied weights and biases |
| Input encoding | Flattened pixel values divided by 255, repeated at every step | Same |
| Simulation length | 25 steps per image | 25 steps; 1 ms timestep |
| Initial state | Zero currents and voltages for each batch | Same |
| Training data | 6,000 stratified images from the official MNIST training split | Identical images |
| Evaluation data | All 10,000 official MNIST test images | Identical images |
| Epochs / optimizer updates | 20 / 940 | Same |
| Batch size | 128; final smaller batch retained | Same |
| Seed / shuffle | 17; shared shuffled order each epoch | Same |
| Training loss | Batch-mean cross-entropy on output membrane voltages, summed over 25 steps | Same |
| Classification | Largest output spike count over 25 steps | Same |
| Gradient propagation | Full backpropagation through all 25 steps | Same |
| Optimizer | Adam | Adam through a custom optimizer callback |
| Learning rate | 0.0005, constant | Same |
| Adam betas / epsilon | (0.9, 0.999) / 1e-8 | Same |
| Weight decay / gradient clipping | None / none | Same |
| Evaluation schedule | Before training and after every epoch, at fixed weights | Same |
| Precision / TF32 | float32 / disabled | Same |
| Deterministic algorithms / CPU threads | Enabled / 4 | Same |
| Execution | Eager PyTorch training loop | Native `sim.train()`; fast projections, eager custom callbacks; compilation disabled |
| Hardware | NVIDIA L4 | NVIDIA L4 |
| Software | snnTorch 1.0.0; PyTorch 2.10.0, CUDA 12.8 | SNNLab 0.12.1 source with unreleased timing support; same PyTorch/CUDA |

SNNLab’s neuron uses a 1 ms timestep to reproduce snnTorch’s per-step decay
factors; snnTorch specifies these factors directly. The SNNLab configuration uses
structural extension validation, with diagnostics and parameter/final/runtime
state retention disabled. These settings describe the measured run; matching
the configuration did not produce identical learning curves.

**Measured Timings**

| Measurement | snnTorch | SNNLab | SNNLab speedup |
| --- | ---: | ---: | ---: |
| Final test accuracy | 85.20% | 80.01% | — |
| Total workflow | 162.39 s | 148.61 s | +9.3% |
| Training only | 59.94 s | 53.46 s | +12.1% |
| Training forward | 27.60 ms | 21.86 ms | +26.2% |
| Backward | 14.09 ms | 14.53 ms | −3.1% |
| Inference forward | 25.75 ms | 23.64 ms | +8.9% |

**Table legend**

1. **Final test accuracy:** percentage of the 10,000 test images classified correctly after epoch 20, using output spike counts.
2. **Total workflow:** setup, all 940 training updates, initial and epoch-end train/test evaluations, and in-memory checkpoints. Excludes data preparation, warmup and disk writes.
3. **Training only:** batch preparation, forward/loss, backward, optimizer updates and bookkeeping across all 940 updates. Excludes evaluation.
4. **Training forward:** fresh-state forward pass with autograd enabled. Excludes loss calculation, backward, optimizer updates and transfers.
5. **Backward:** backpropagation through a freshly prepared graph. Excludes forward/loss preparation, gradient clearing, optimizer updates and transfers.
6. **Inference forward:** fresh-state forward pass with autograd disabled. Excludes transfers.
7. **SNNLab speedup:** `100 × (snnTorch time / SNNLab time − 1)`. Positive means faster; negative means slower. This is a speed ratio, not the percentage reduction in elapsed time.

Whole-workflow timings used one L4 per library concurrently. Isolated forward,
backward and inference timings used randomized passes on one L4: medians of 150
samples per library and operation across three shared weight states, after warmup.
Each sample processes 128 images × 25 steps. Isolated timings do not sum to the
training-only time. Timing instrumentation preserved each library’s learning
history; results apply to this workload and hardware.
