## Use snnlab in a project

```sh
uv add git+https://github.com/eoinmurray/snnlab
```

For reproducible work, pin a Git tag or commit and commit your project's lockfile. The distribution declares Python 3.10 or newer; dependency availability can further constrain the interpreter and platform you use.

```python
from snnlab import lang, sim, viz
```

## Develop from this checkout

Run from the repository root:

```sh
uv sync --dev
uv run snnsim --help
```

Use an editable dependency in a sibling project:

```sh
uv add --editable ../snnlab
```

## Optional system tools

| Tool | Required for |
| --- | --- |
| Graphviz (`dot`) | SVG and PNG diagram exports |
| FFmpeg | Video exports |

Install these with your operating system package manager. Core authoring and simulation do not require either executable. The [quickstart](/quickstart) writes a bundle without diagram rendering.

## Documentation site

The separate Next.js app lives in `docs/`. Use Node.js 22 or newer:

```sh
cd docs
npm ci
npm run dev
```

Open `http://localhost:3000`. See [development](/development) for build and documentation commands.
