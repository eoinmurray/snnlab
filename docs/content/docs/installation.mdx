## Install snnlab

Add snnlab to your Python project from PyPI:

```sh
uv add snnlab
```

For a pip-managed environment:

```sh
python -m pip install snnlab
```

snnlab requires Python 3.10 or newer. Commit your project's lockfile when using uv to preserve the resolved dependency versions.

## Check the installation

```python
from snnlab import lang, sim, viz
```

Continue with the [quickstart](/quickstart) to build and simulate a small circuit.
