This example implements the established single-compartment Hodgkin–Huxley model through [custom neuron and synapse extensions](/api/extensions#implementing-extensions). Sodium and potassium channels generate the action-potential waveform; there is no threshold-triggered voltage reset. One cell receives a 0.1 nA current pulse from 10 to 70 ms during a 100 ms recording.

![A continuous pulse input drives one custom Hodgkin–Huxley neuron through a memoryless current-injection projection.](/hodgkin-huxley/network.png)

The model follows [Hodgkin and Huxley (1952)](https://doi.org/10.1113/jphysiol.1952.sp004764), expressed in the modern absolute-voltage convention with resting voltage near −65 mV. Rates describe the classic squid-axon parameterization at 6.3 °C, with no temperature rescaling. The small membrane area and snnlab extension wrapper are choices for this example, rather than new channel equations.

## Membrane and channel equations

The membrane obeys

$$
C_m\frac{dV}{dt}=I_{\mathrm{inj}}
-\bar g_{\mathrm{Na}}m^3h(V-E_{\mathrm{Na}})
-\bar g_{\mathrm{K}}n^4(V-E_{\mathrm{K}})
-g_L(V-E_L).
$$

Here $t$ is time in ms, $V$ is membrane voltage in mV, $C_m$ is capacitance in nF, and $I_{\mathrm{inj}}$ is net injected current in nA. The maximal sodium and potassium conductances are $\bar g_{\mathrm{Na}}$ and $\bar g_{\mathrm{K}}$ in µS; $g_L$ is leak conductance in µS. Their reversal voltages $E_{\mathrm{Na}}$, $E_{\mathrm{K}}$ and $E_L$ are in mV. Dimensionless gates $m$, $h$ and $n$ describe sodium activation, sodium inactivation and potassium activation, respectively. The instantaneous sodium and potassium conductances are $\bar g_{\mathrm{Na}}m^3h$ and $\bar g_{\mathrm{K}}n^4$.

For each gate $x\in\{m,h,n\}$,

$$
\frac{dx}{dt}=\alpha_x(V)(1-x)-\beta_x(V)x,
\qquad
x(0)=\frac{\alpha_x(V_0)}{\alpha_x(V_0)+\beta_x(V_0)}.
$$

Here $\alpha_x$ and $\beta_x$ are voltage-dependent opening and closing rates in ms$^{-1}$, and $V_0=-65$ mV is the initial voltage. Initial gates are at their steady-state values for $V_0$. To display the conventional rate formulas without implicit physical units in exponential arguments, define the dimensionless voltage $v=V/(1\,\mathrm{mV})$. The table gives numerical rate values in ms$^{-1}$:

| Gate | $\alpha_x$ | $\beta_x$ |
| --- | --- | --- |
| $m$ | $0.1(v+40)/(1-e^{-(v+40)/10})$ | $4e^{-(v+65)/18}$ |
| $h$ | $0.07e^{-(v+65)/20}$ | $1/(1+e^{-(v+35)/10})$ |
| $n$ | $0.01(v+55)/(1-e^{-(v+55)/10})$ | $0.125e^{-(v+65)/80}$ |

The apparent singularities at −40 mV for $\alpha_m$ and −55 mV for $\alpha_n$ are removable. Their limiting rates are 1 and 0.1 ms$^{-1}$, respectively. The PyTorch implementation uses `expm1` with a local series expansion; the independent SciPy implementation uses `scipy.special.exprel`.

### Parameters and physical units

The example uses a 1,000 µm² patch, equivalent to $10^{-5}$ cm². Multiplying the classic density parameters by this area gives whole-cell values compatible with snnlab:

| Parameter | Density formulation | Extension value |
| --- | --- | --- |
| Capacitance | 1 µF/cm² | 0.01 nF |
| Maximal sodium conductance | 120 mS/cm² | 1.2 µS |
| Maximal potassium conductance | 36 mS/cm² | 0.36 µS |
| Leak conductance | 0.3 mS/cm² | 0.003 µS |
| Sodium reversal | 50 mV | 50 mV |
| Potassium reversal | −77 mV | −77 mV |
| Leak reversal | −54.387 mV | −54.387 mV |
| Pulse current | 10 µA/cm² | 0.1 nA |

`input_unit="nA"` describes the injected input, while the neuron's intrinsic channels remain conductance-based. The registered memoryless synapse simply forwards the weight-projected current; it does not add synaptic filtering. In this example, `I_inj = excitatory - inhibitory`.

## Voltage, gates and spikes

![Membrane voltage, sodium and potassium gating variables, and the injected current pulse over 100 ms.](/hodgkin-huxley/hodgkin-huxley.png)

The pulse produces 5 spikes. Sodium activation rises rapidly during each upstroke; sodium inactivation and potassium activation contribute to repolarization. Potassium activation then relaxes during the afterhyperpolarization. These changes emerge from the channel equations, without a reset rule or an imposed refractory hold.

The network timestep is 0.05 ms. Within each network step, the callback integrates all four differential equations together using classical fourth-order Runge–Kutta (RK4), subdividing into steps no larger than 0.025 ms. Input current is held constant during each network step. Gates are not clipped to force them into their physical interval.

A binary spike marks an upward crossing of 0 mV during any internal substep. It is reported in that network step, while the continuous voltage keeps evolving. Recorded voltage/gates correspond to the end of each step, so plots use $(k+1)\Delta t$: $k$ is the zero-based step index and $\Delta t$ is the network timestep. The unused runtime refractory tensor is preserved. At most one event is returned per network step; coarse network timesteps can lose event multiplicity even when internal integration remains fine.

## Compare with SciPy

The reference separately implements the density equations using NumPy, then calls SciPy's adaptive [DOP853 solver](https://docs.scipy.org/doc/scipy/reference/generated/scipy.integrate.solve_ivp.html) in float64. It does not call the PyTorch rate, derivative or integration functions. It restarts integration at 10 and 70 ms so the solver does not step across either current discontinuity, and samples its dense solution at exactly the same end-of-step times as snnlab.

![Overlaid snnlab and SciPy voltage trajectories, their signed voltage difference, and errors in all three channel gates.](/hodgkin-huxley/scipy-comparison.png)

The reference uses relative tolerance `rtol=1e-10` and absolute tolerance `atol=1e-12`. The following measurements are generated from the same run as the plotted comparison:

| Measurement | Recorded value |
| --- | --- |
| snnlab state precision | float32 |
| Maximum absolute voltage difference | 0.008901 mV |
| Voltage root mean square difference | 0.0006599 mV |
| Maximum absolute $m$ difference | 0.00006597 |
| Maximum absolute $h$ difference | 0.00001106 |
| Maximum absolute $n$ difference | 0.00001420 |
| snnlab / SciPy spike count | 5 / 5 |
| Maximum paired spike-time difference | 0.04866 ms |

These are numerical agreement measurements for this pulse protocol, not validation against biological recordings or a general accuracy bound. Spike times in snnlab are quantized to the 0.05 ms output grid, whereas SciPy locates continuous upward-crossing events. The plotted error combines finite-step RK4 error with float32 rounding; it should not be attributed solely to the integration method. The automated test checks the voltage and gate trajectories, paired spike times, physical gate bounds, resting behavior, and finite rate values/gradients at the removable singularities.

## Extension callbacks

The initializer supplies voltage and the three gates. `state_units` exposes each gate for recording; the executor adds the standard refractory tensor. The step returns the updated tensor state and binary events. Callback references remain importable through `example.py` when a compiled bundle is reloaded in another process. See [Custom Neurons and Synapses](/custom-neurons-and-synapses) for the registration contract.

```python title="example.py — callbacks"
CAPACITANCE_NF = 0.01
G_NA_US, G_K_US, G_LEAK_US = 1.2, 0.36, 0.003
E_NA_MV, E_K_MV, E_LEAK_MV = 50.0, -77.0, -54.387
MAX_STEP_MS = 0.025


def _vtrap(x):
    small = x.abs() < 1e-4
    safe = torch.where(
        small,
        torch.ones_like(x),
        x,
    )
    return torch.where(
        small,
        1 + x / 2 + x.square() / 12,
        safe / -torch.expm1(-safe),
    )


def rates(voltage):
    return (
        (_vtrap((voltage + 40) / 10), 4 * torch.exp(-(voltage + 65) / 18)),
        (0.07 * torch.exp(-(voltage + 65) / 20), torch.sigmoid((voltage + 35) / 10)),
        (0.1 * _vtrap((voltage + 55) / 10), 0.125 * torch.exp(-(voltage + 65) / 80)),
    )


def initial_state(context):
    voltage = torch.full(
        context.shape,
        -65.0,
        device=context.device,
        dtype=context.dtype,
    )
    state = {"voltage": voltage}
    for gate, (alpha, beta) in zip(
        ("m", "h", "n"),
        rates(voltage),
    ):
        state[gate] = alpha / (alpha + beta)
    return state


def _derivative(
    values,
    current,
):
    voltage, m, h, n = values
    ionic = (
        G_NA_US * m**3 * h * (voltage - E_NA_MV)
        + G_K_US * n**4 * (voltage - E_K_MV)
        + G_LEAK_US * (voltage - E_LEAK_MV)
    )
    gates = tuple(
        alpha * (1 - gate) - beta * gate
        for gate, (alpha, beta) in zip(
            (m, h, n),
            rates(voltage),
        )
    )
    return ((current - ionic) / CAPACITANCE_NF, *gates)


def step(context):
    keys = ("voltage", "m", "h", "n")
    values = tuple(context.state[key] for key in keys)
    current = (context.excitatory - context.inhibitory).to(values[0].dtype)
    substeps = max(
        1,
        math.ceil(context.dt_ms / MAX_STEP_MS),
    )
    dt = context.dt_ms / substeps
    crossed = torch.zeros_like(
        values[0],
        dtype=torch.bool,
    )
    for _ in range(substeps):
        k1 = _derivative(
            values,
            current,
        )
        k2 = _derivative(
            tuple(
                y + dt / 2 * k
                for y, k in zip(
                    values,
                    k1,
                )
            ),
            current,
        )
        k3 = _derivative(
            tuple(
                y + dt / 2 * k
                for y, k in zip(
                    values,
                    k2,
                )
            ),
            current,
        )
        k4 = _derivative(
            tuple(
                y + dt * k
                for y, k in zip(
                    values,
                    k3,
                )
            ),
            current,
        )
        updated = tuple(
            y + dt / 6 * (a + 2 * b + 2 * c + d)
            for y, a, b, c, d in zip(
                values,
                k1,
                k2,
                k3,
                k4,
            )
        )
        crossed = crossed | ((values[0] < 0) & (updated[0] >= 0))
        values = updated
    return {
        **context.state,
        **dict(
            zip(
                keys,
                values,
            )
        ),
    }, crossed.to(values[0].dtype)


def current_step(context):
    return {"value": context.drive.to(context.state["value"].dtype)}
```

DT_MS = 0.05
DURATION_MS = 100.0
PULSE_START_MS, PULSE_STOP_MS = 10.0, 70.0
CURRENT_NA = 0.1
OUTPUT_DIR = Path(__file__).resolve().parent / "results"
OUTPUT_PATH = OUTPUT_DIR / "hodgkin-huxley.png"


def prepare_results():
    if OUTPUT_DIR.is_symlink():
        OUTPUT_DIR.unlink()
    elif OUTPUT_DIR.exists():
        shutil.rmtree(OUTPUT_DIR)
    OUTPUT_DIR.mkdir(parents=True)


def build_example(dt_ms=DT_MS):

    extensions.register_neuron(
        "example.hodgkin_huxley/v1",
        step,
        initialize=initial_state,
        input_unit="nA",
        state_units={
            "m": "1",
            "h": "1",
            "n": "1",
        },
        capture_safe=True,
    )
    extensions.register_synapse(
        "example.injected_current/v1",
        current_step,
        output_unit="nA",
        capture_safe=True,
    )
    net = lang.Network(
        "hodgkin_huxley",
        dt=dt_ms * lang.ms,
    )
    pulse = net.input(
        "pulse",
        shape=("time", "batch", 1),
        signal_type="continuous",
        unit="1",
    )
    cells = net.population(
        "axon",
        size=1,
        neuron=lang.CustomNeuron("example.hodgkin_huxley/v1"),
    )
    injection = net.connect(
        pulse,
        cells.excitatory,
        name="injection",
        synapse=lang.CustomSynapse("example.injected_current/v1"),
        weight=lang.Constant(CURRENT_NA),
        initialization_scaling="direct",
    )
    net.output(
        "voltage",
        cells.voltage,
    )
    net.output(
        "spikes",
        cells.spikes,
    )
    net.output(
        "current",
        injection.current,
    )
    for gate in ("m", "h", "n"):
        net.output(
            gate,
            cells.state(gate),
        )
    bundle = lang.compile(
        net,
        target="tools/snnsim",
    )
    stimulus = torch.zeros(
        round(DURATION_MS / dt_ms),
        1,
        1,
    )
    stimulus[round(PULSE_START_MS / dt_ms) : round(PULSE_STOP_MS / dt_ms)] = 1
    return bundle, stimulus


def run_example(*, render_diagram=False):
    bundle, stimulus = build_example()
    if render_diagram:
        viz.render_diagram(
            lang.diagram(
                bundle,
                view="expanded",
            ),
            OUTPUT_PATH.with_name("network.png"),
            scale=2,
            height_to_width_ratio=None,
        )
    result = simulate(
        graph=bundle.graph,
        device="cpu",
        input_bindings=(
            DenseArrayBinding(
                "pulse",
                stimulus,
            ),
        ),
        performance=Performance(compile_mode=None),
        extension_validation="strict",
    ).numpy(batch=0)
    return result

def _rates(v):
    alpha = np.array(
        [
            1 / exprel(-(v + 40) / 10),
            0.07 * np.exp(-(v + 65) / 20),
            0.1 / exprel(-(v + 55) / 10),
        ]
    )
    beta = np.array(
        [
            4 * np.exp(-(v + 65) / 18),
            1 / (1 + np.exp(-(v + 35) / 10)),
            0.125 * np.exp(-(v + 65) / 80),
        ]
    )
    return alpha, beta


def solve_reference(
    times,
    *,
    pulse_start_ms=10.0,
    pulse_stop_ms=70.0,
    current_na=0.1,
):
    alpha, beta = _rates(-65)
    initial = np.r_[-65, alpha / (alpha + beta)]
    reference = np.empty((4, len(times)))
    event_times = []

    def crossing(
        t,
        y,
    ):
        return y[0]

    crossing.direction = 1
    for start, stop, current in (
        (0, pulse_start_ms, 0),
        (pulse_start_ms, pulse_stop_ms, current_na * 100),
        (pulse_stop_ms, float(times[-1]), 0),
    ):

        def derivative(
            t,
            y,
        ):
            v, m, h, n = y
            ionic = (
                120 * m**3 * h * (v - 50) + 36 * n**4 * (v + 77) + 0.3 * (v + 54.387)
            )
            a, b = _rates(v)
            return np.r_[current - ionic, a * (1 - y[1:]) - b * y[1:]]

        solution = solve_ivp(
            derivative,
            (start, stop),
            initial,
            method="DOP853",
            rtol=1e-10,
            atol=1e-12,
            dense_output=True,
            events=crossing,
        )
        if not solution.success:
            raise RuntimeError(solution.message)
        mask = (times > start) & (times <= stop)
        reference[:, mask] = solution.sol(times[mask])
        initial = solution.y[:, -1]
        event_times.extend(solution.t_events[0])
    return reference, np.asarray(event_times)


def compare(
    result,
    dt_ms=DT_MS,
):
    outputs = {name: value.ravel() for name, value in result.outputs.items()}
    times = (np.arange(len(outputs["voltage"])) + 1) * dt_ms
    reference, reference_spikes = solve_reference(
        times,
        pulse_start_ms=PULSE_START_MS,
        pulse_stop_ms=PULSE_STOP_MS,
        current_na=CURRENT_NA,
    )
    actual = np.stack([outputs[key] for key in ("voltage", "m", "h", "n")])
    error = actual - reference
    spike_times = times[outputs["spikes"] > 0]
    if len(spike_times) != len(reference_spikes):
        raise ValueError(
            f"Spike count mismatch: snnlab={len(spike_times)}, SciPy={len(reference_spikes)}"
        )
    metrics = {
        "network_dt_ms": dt_ms,
        "rk4_max_substep_ms": MAX_STEP_MS,
        "state_dtype": "float32",
        "reference_solver": "DOP853",
        "reference_rtol": 1e-10,
        "reference_atol": 1e-12,
        "voltage_max_abs_error_mv": float(np.abs(error[0]).max()),
        "voltage_rmse_mv": float(np.sqrt(np.mean(error[0] ** 2))),
        "gate_max_abs_error": {
            gate: float(np.abs(error[i]).max())
            for i, gate in enumerate(
                ("m", "h", "n"),
                1,
            )
        },
        "snnlab_spike_times_ms": spike_times.tolist(),
        "scipy_spike_times_ms": reference_spikes.tolist(),
        "max_spike_time_error_ms": float(np.abs(spike_times - reference_spikes).max())
        if len(spike_times)
        else 0.0,
    }
    return times, actual, reference, metrics

    times, actual, reference, metrics = compare(result)
    fig, axes = plt.subplots(

        1,
        figsize=(9, 7),

        constrained_layout=True,

    axes[0].plot(
        times,

    )
    axes[0].plot(
        times,

        linewidth=1,
    )
    axes[0].set(
        ylabel="Voltage (mV)",
        title="HH extension compared with an independent SciPy solution",
    )
    axes[0].legend(loc="upper right")
    axes[1].plot(
        times,
        actual[0] - reference[0],
        color="#b33b33",
        linewidth=1,
    )
    axes[1].set(ylabel="Voltage error (mV)")
    for index, gate in enumerate(
        ("m", "h", "n"),
        1,
    ):
        axes[2].plot(
            times,
            actual[index] - reference[index],
            label=gate,
        )
    axes[2].set(

def _rates(v):
    alpha = np.array(
        [
            1 / exprel(-(v + 40) / 10),
            0.07 * np.exp(-(v + 65) / 20),
            0.1 / exprel(-(v + 55) / 10),
        ]
    )
    beta = np.array(
        [
            4 * np.exp(-(v + 65) / 18),
            1 / (1 + np.exp(-(v + 35) / 10)),
            0.125 * np.exp(-(v + 65) / 80),
        ]
    )
    return alpha, beta


def solve_reference(
    times,
    *,
    pulse_start_ms=10.0,
    pulse_stop_ms=70.0,
    current_na=0.1,
):
    alpha, beta = _rates(-65)
    initial = np.r_[-65, alpha / (alpha + beta)]
    reference = np.empty((4, len(times)))
    event_times = []

    def crossing(
        t,
        y,
    ):
        return y[0]

    crossing.direction = 1
    for start, stop, current in (
        (0, pulse_start_ms, 0),
        (pulse_start_ms, pulse_stop_ms, current_na * 100),
        (pulse_stop_ms, float(times[-1]), 0),
    ):

        def derivative(
            t,
            y,
        ):
            v, m, h, n = y
            ionic = (
                120 * m**3 * h * (v - 50) + 36 * n**4 * (v + 77) + 0.3 * (v + 54.387)
            )
            a, b = _rates(v)
            return np.r_[current - ionic, a * (1 - y[1:]) - b * y[1:]]

        solution = solve_ivp(
            derivative,
            (start, stop),
            initial,
            method="DOP853",
            rtol=1e-10,
            atol=1e-12,
            dense_output=True,
            events=crossing,
        )
        if not solution.success:
            raise RuntimeError(solution.message)
        mask = (times > start) & (times <= stop)
        reference[:, mask] = solution.sol(times[mask])
        initial = solution.y[:, -1]
        event_times.extend(solution.t_events[0])
    return reference, np.asarray(event_times)


def compare(
    result,
    dt_ms=DT_MS,
):
    outputs = {name: value.ravel() for name, value in result.outputs.items()}
    times = (np.arange(len(outputs["voltage"])) + 1) * dt_ms
    reference, reference_spikes = solve_reference(
        times,
        pulse_start_ms=PULSE_START_MS,
        pulse_stop_ms=PULSE_STOP_MS,
        current_na=CURRENT_NA,
    )
    actual = np.stack([outputs[key] for key in ("voltage", "m", "h", "n")])
    error = actual - reference
    spike_times = times[outputs["spikes"] > 0]
    if len(spike_times) != len(reference_spikes):
        raise ValueError(
            f"Spike count mismatch: snnlab={len(spike_times)}, SciPy={len(reference_spikes)}"
        )
    metrics = {
        "network_dt_ms": dt_ms,
        "rk4_max_substep_ms": MAX_STEP_MS,
        "state_dtype": "float32",
        "reference_solver": "DOP853",
        "reference_rtol": 1e-10,
        "reference_atol": 1e-12,
        "voltage_max_abs_error_mv": float(np.abs(error[0]).max()),
        "voltage_rmse_mv": float(np.sqrt(np.mean(error[0] ** 2))),
        "gate_max_abs_error": {
            gate: float(np.abs(error[i]).max())
            for i, gate in enumerate(
                ("m", "h", "n"),
                1,
            )
        },
        "snnlab_spike_times_ms": spike_times.tolist(),
        "scipy_spike_times_ms": reference_spikes.tolist(),
        "max_spike_time_error_ms": float(np.abs(spike_times - reference_spikes).max())
        if len(spike_times)
        else 0.0,
    }
    return times, actual, reference, metrics


def plot_comparison(result):
