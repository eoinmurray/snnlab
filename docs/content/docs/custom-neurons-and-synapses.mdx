title: Custom Neurons and Synapses
description: Write vectorized custom neurons and synapses for compiled execution and eligible CUDA replay, using a matched adaptation comparison.
---

Building on [Current-based LIF](/current-lif), this example asks a simple question: **how does spike-triggered adaptation change a neuron's response to sustained input?** Four input channels drive two populations of eight cells with exactly the same weights and registered exponential current synapses. One uses the built-in `CUBA_LIF`; the other uses a registered Python neuron definition that builds an opposing current after each spike. Both custom updates operate on whole tensors, preserve state dtype and can compile without a decorator.

![Four input channels connect through exponential current synapses to standard and adaptive populations, each with eight cells and its own spike output.](/customisation/network.png)

The stimulus starts at 20 Hz, rises to 120 Hz between 100 and 400 ms, then returns to 20 Hz. The custom population's adaptation builds up during stimulation and decays afterwards. This is an illustrative discrete-time adaptive model; it is not a claim that one parameterization describes every biological neuron.

Run from the repository root:

```bash
uv run python examples/customisation/customisation.py
uv run python examples/customisation/customisation.py --simulate
uv run python examples/customisation/customisation.py --simulate --eager --extension-validation strict
```

The first command builds and saves `network.bundle`, `network.png`, `customisation.png` and `metrics.json` beside itself. The second starts a fresh process, loads the saved bundle and regenerates the same seeded stimulus without registering definitions or rebuilding the network. The third selects eager execution and strict callback value checks for debugging. Keep `custom_neurons.py` beside the script so its callbacks are importable. A missing bundle raises `FileNotFoundError`; a missing callback module raises a descriptive error. Graphviz's `dot` executable is needed for the diagram. In a headless environment you can set `MPLBACKEND=Agg` when running the script.

The default device is CPU. Use `--simulate --device cuda:0` on a CUDA host;
that option changes execution placement without changing the fixed CPU-generated
stimulus. This small plotting example is not a throughput benchmark. The
[Performance and Custom Components guide](/performance-and-custom-components)
explains compilation, replay eligibility, mixed precision and current limits.

## 1. Define the custom neuron

A custom neuron has an initial tensor state and a step function. Put these functions in `custom_neurons.py`, an importable module outside the bundle. The step receives previous state, excitatory and inhibitory input, timestep, configuration and a spike function compatible with the run's surrogate gradient.

```python
def validate_adaptive(config):
    for name in ("tau_mem_ms", "tau_adapt_ms"):
        if not math.isfinite(config[name]) or config[name] <= 0:
            raise ValueError(f"{name} must be finite and positive")
    if not math.isfinite(config["adaptation_na"]) or config["adaptation_na"] < 0:
        raise ValueError("adaptation_na must be finite and nonnegative")


def adaptive_initial_state(context):
    shape, device, dtype = context.shape, context.device, context.dtype
    return {
        "voltage": torch.full(shape, -65.0, device=device, dtype=dtype),
        "adaptation": torch.zeros(shape, device=device, dtype=dtype),
    }


def adaptive_step(context):
    voltage = context.state["voltage"]
    adaptation = context.state["adaptation"]
    beta = math.exp(-context.dt_ms / context.config["tau_mem_ms"])
    # State retains its dtype even when an upstream CUDA matmul uses BF16.
    current = (
        context.excitatory.to(voltage.dtype)
        - context.inhibitory.to(voltage.dtype)
        - adaptation
    )
    voltage = (
        -65
        + (voltage + 65) * beta
        + current * context.config["tau_mem_ms"] * (1 - beta)
    )
    spikes = context.spike(voltage + 50)
    # Broadcast the reset scalar; no per-step full-sized reset allocation.
    voltage = torch.where(spikes.bool(), -65.0, voltage)
    adaptation = adaptation * math.exp(-context.dt_ms / context.config["tau_adapt_ms"])
    adaptation = adaptation + spikes * context.config["adaptation_na"]
    return {**context.state, "voltage": voltage, "adaptation": adaptation}, spikes
```

The initial state provides voltage and adaptation. The executor adds a zero-valued integer refractory tensor when absent. The step returns the updated state and binary spikes. Here adaptation subtracts from the net current and increases by `adaptation_na` after each spike; its exponential decay is controlled by `tau_adapt_ms`.

The ordinary `adaptive_step(context)` compiles by default alongside the built-in neuron update. Its PyTorch expressions operate on the whole batch/population; `torch.where` broadcasts a scalar reset without a Python branch or a full-sized reset allocation. Incoming currents are converted to the voltage state's dtype so BF16 matrix products do not change the recurrent state contract. The exponential factors depend only on fixed configuration and can specialize during tracing. Configuration validation runs before updates. Keep state keys/shapes/devices/dtypes stable, use `context.spike` for gradients, and avoid `.item()`, `.cpu()`, NumPy conversions or loops over cells inside the step. No compilation decorator is required.

`state_units` makes adaptation available through `population.state("adaptation")`. For callback contracts and additional extension categories, see [Extensions](/api/lang/extensions).

## 2. Define the custom synapse

```python
def validate_exponential(config):
    if not math.isfinite(config["tau_ms"]) or config["tau_ms"] <= 0:
        raise ValueError("tau_ms must be finite and positive")


def exponential_initial_state(context):
    return {
        "value": torch.zeros(context.shape, device=context.device, dtype=context.dtype)
    }


def exponential_step(context):
    previous = context.state["value"]
    # Configuration is fixed per prepared kernel; the scalar specializes.
    decay = math.exp(-context.dt_ms / context.config["tau_ms"])
    drive = context.drive.to(previous.dtype)
    return {**context.state, "value": previous * decay + drive}
```

The executor supplies `drive` after delay routing and weight projection. The
callback filters that current with the same 5 ms exponential recurrence as the
built-in `ExponentialCurrent`; it does not multiply weights again. Its state is
one `(batch, cells)` tensor allocated on the requested device/dtype. Casting the
drive to the previous state's dtype preserves that state under autocast. The
step returns new tensors and a new mapping, leaving previous state untouched.

Both populations use this same synapse implementation and the same parameter,
so the comparison still isolates neuron adaptation.

## 3. Define a custom weight distribution

```python
def clipped_normal(shape, config, *, device, dtype):
    values = torch.randn(shape, device=device, dtype=dtype)
    return (values * config["std"] + config["mean"]).clamp(min=config["minimum"])
```

The initializer receives the runtime shape, configuration, device and dtype. It draws normal values and clips them at a configurable minimum. With the default initialization scaling, projection initialization subsequently divides by fan-in, and then applies the declared constraint. Keep this function in `custom_neurons.py` too.

This initializer draws the whole weight tensor on the requested device with the requested dtype. Initialization runs eagerly during setup to preserve seeded draws; speeding up per-timestep dynamics is separate. Repeated custom weight constraints compile after optimizer updates. Prefer whole-tensor expressions such as `parameter.clamp(...)` to loops over weights; see [Weights](/weights#efficient-custom-initializers-and-constraints).

Register the callbacks by their `module:function` references when building the network:

```python
def register_definitions():
    extensions.register_neuron(
        "example.adaptive_lif/v1",
        "custom_neurons:adaptive_step",
        initialize="custom_neurons:adaptive_initial_state",
        input_unit="nA",
        state_units={"adaptation": "nA"},
        validate="custom_neurons:validate_adaptive",
        capture_safe=True,
    )
    extensions.register_synapse(
        "example.exponential_current/v1",
        "custom_neurons:exponential_step",
        initialize="custom_neurons:exponential_initial_state",
        output_unit="nA",
        validate="custom_neurons:validate_exponential",
        capture_safe=True,
    )
    extensions.register_initializer(
        # Random weight initialization happens once, outside replay.
        "example.clipped_normal/v1",
        "custom_neurons:clipped_normal",
    )
```

Registration assigns stable, versioned names. The bundle stores those names, import references, units and configuration. Each process loads the referenced module automatically; the module does not need to register itself. For installed extensions, declare `package="distribution-name"` to record and check its exact installed version. Change the versioned definition name when its semantics change.

The neuron and synapse registrations declare `capture_safe=True`: their
initializers are deterministic allocations, and their updates have no random
draws, host reads or Python side effects. This permits eligible CUDA replay;
it does not itself enable replay or compiled timestep blocks. The random weight
initializer runs once during setup and remains outside capture. Keep strict
validation for development; structural validation is the execution default.

See [Parameters](/api/lang/parameters#custom-initializers-and-constraints).

## 4. Define inputs and the network

```python
steps = round(DURATION_MS / DT_MS)
rates = torch.full((steps, 1, 4), 20.0)
rates[round(100 / DT_MS) : round(400 / DT_MS)] = 120.0
generator = torch.Generator().manual_seed(SEED)
input_spikes = (
    torch.rand(rates.shape, generator=generator) < rates * DT_MS / 1000
).float()
binding = DenseArrayBinding("inputs", input_spikes)

# Compare built-in and custom neuron dynamics with matched input weights.
if not args.simulate:
    register_definitions()
    net = lang.Network("customisation", dt=DT_MS * lang.ms)
    inputs = net.input(
        "inputs", shape=("time", "batch", 4), signal_type="spikes", unit="spike"
    )
    standard = net.population(
        "standard", size=8, neuron=lang.CUBA_LIF(tau_mem=20 * lang.ms)
    )
    adaptive = net.population(
        "adaptive",
        size=8,
        neuron=lang.CustomNeuron(
            "example.adaptive_lif/v1",
            tau_mem_ms=20,
            tau_adapt_ms=100,
            adaptation_na=0.35,
        ),
    )
    weights = net.parameter(
        "weights",
        shape=(8, 4),
        unit="nA",
        initializer=lang.CustomInitializer(
            "example.clipped_normal/v1", mean=5.0, std=1.0, minimum=0.0
        ),
        constraint=lang.NonNegative(),
    )
    for cells in (standard, adaptive):
        projection = net.connect(
            inputs,
            cells.excitatory,
            name=f"input_to_{cells.id}",
            synapse=lang.CustomSynapse(
                "example.exponential_current/v1", tau_ms=5.0
            ),
            weight=weights,
        )
        net.output(f"{cells.id}_spikes", cells.spikes)
        net.expose(cells.voltage, name=f"{cells.id}_voltage")
        net.expose(projection.current, name=f"{cells.id}_current")
    net.expose(inputs, name="input_spikes")
    net.expose(adaptive.state("adaptation"), name="adaptation")

    bundle = lang.compile(net, target="tools/snnsim")
    bundle.write(bundle_path)
```

`DenseArrayBinding` supplies the custom stimulus. The shared parameter has graph shape `(8, 4)` and unit `"nA"`; both projections reference it, so differences in response come from neuron dynamics. `CustomSynapse("example.exponential_current/v1", tau_ms=5.0)` adds incoming spike-weighted current and lets it decay with a 5 ms time constant. Inhibitory current projections would subtract from membrane drive.

The standard neuron uses the new [CUBA_LIF](/api/lang/components#current-based-lif), and the adaptive population uses `CustomNeuron`. Both expect current input. Mixing these with a conductance synapse is rejected rather than silently interpreting incompatible units.

## 5. Declare outputs and diagnostics

The loop declares official spike outputs and exposes voltage and synaptic current for both populations. The custom adaptation signal is also exposed. `.current` belongs to current-based projections; `.conductance` belongs to conductance-based projections.

Custom state ports participate in normal outputs, diagnostics and operations. Their declared units and `(time, batch, cells)` axes are preserved in the compiled graph's signal validation.

## 6. Compile and simulate

```python
bundle = lang.load_bundle(bundle_path)
viz.render_diagram(
    lang.diagram(bundle, view="expanded"),
    OUTPUT_DIR / "network.png",
    scale=2,
    height_to_width_ratio=None,
    canvas_size=(1920, 900),
)
result = simulate(
    bundle=bundle_path,
    input_bindings=(binding,),
    seed=SEED,
    device=args.device,
    performance=Performance(compile_mode=None if args.eager else "default"),
    extension_validation=args.extension_validation,
)
(OUTPUT_DIR / "metrics.json").write_text(
    json.dumps(result.metrics, indent=2, allow_nan=False) + "\n"
)
data = result.numpy(batch=0)
assert data.time_ms is not None
```

The graph and manifest list required extension names and callback references. `lang.load_bundle` and the simulator resolve these references automatically from modules available in the current environment. The graph digest covers the implementation references; Python source and pickled functions are never saved in the bundle. Additional custom state is included in runtime continuation artifacts, so splitting an execution does not reset adaptation or synaptic history.

`Performance()` retains automatic compilation, precision and replay policies.
This example selects eager execution only with `--eager`. Custom neurons and
synapses currently use the individual compiled-kernel loop; they do not use
compiled timestep blocks even when marked capture-safe. The single CPU
simulation does not replay a CUDA Graph. Eligible repeated CUDA shapes can
replay, and the registrations above permit that path. See
`metrics.json` → `performance` for requested settings, selected paths and fallback
reasons. Exposed diagnostic histories are retained for the plots and add work.

```python title="examples/customisation/customisation.py"
"""Compare a built-in current LIF with a registered adaptive current neuron.

Run from the repository root: uv run python examples/customisation/customisation.py
Outputs are saved beside this script. Diagram rendering requires Graphviz.
"""

import argparse
import json
from pathlib import Path

import numpy as np
import torch

from snnlab import extensions, lang, viz
from snnlab.sim import (
    DenseArrayBinding,
    Performance,
    simulate,
)

OUTPUT_DIR = Path(__file__).resolve().parent
DT_MS = 0.5
DURATION_MS = 500
SEED = 17


# Register references to functions in the sibling importable module.
def register_definitions():
    extensions.register_neuron(
        "example.adaptive_lif/v1",
        "custom_neurons:adaptive_step",
        initialize="custom_neurons:adaptive_initial_state",
        input_unit="nA",
        state_units={"adaptation": "nA"},
        validate="custom_neurons:validate_adaptive",
        capture_safe=True,
    )
    extensions.register_synapse(
        "example.exponential_current/v1",
        "custom_neurons:exponential_step",
        initialize="custom_neurons:exponential_initial_state",
        output_unit="nA",
        validate="custom_neurons:validate_exponential",
        capture_safe=True,
    )
    extensions.register_initializer(
        # Random weight initialization happens once, outside replay.
        "example.clipped_normal/v1",
        "custom_neurons:clipped_normal",
    )


def main():
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument(
        "--simulate",
        action="store_true",
        help="Load the saved bundle in a fresh process; do not build or register definitions.",
    )
    parser.add_argument(
        "--device", default="cpu", help="Torch device, e.g. cpu or cuda:0"
    )
    parser.add_argument(
        "--eager", action="store_true", help="Disable runtime compilation"
    )
    parser.add_argument(
        "--extension-validation", choices=("structural", "strict"), default="structural"
    )
    args = parser.parse_args()
    bundle_path = OUTPUT_DIR / "network.bundle"
    # 4. Define a stimulus with custom tensors: quiet, then sustained activity.
    steps = round(DURATION_MS / DT_MS)
    rates = torch.full((steps, 1, 4), 20.0)
    rates[round(100 / DT_MS) : round(400 / DT_MS)] = 120.0
    generator = torch.Generator().manual_seed(SEED)
    input_spikes = (
        torch.rand(rates.shape, generator=generator) < rates * DT_MS / 1000
    ).float()
    binding = DenseArrayBinding("inputs", input_spikes)

    # Compare built-in and custom neuron dynamics with matched input weights.
    if not args.simulate:
        register_definitions()
        net = lang.Network("customisation", dt=DT_MS * lang.ms)
        inputs = net.input(
            "inputs", shape=("time", "batch", 4), signal_type="spikes", unit="spike"
        )
        standard = net.population(
            "standard", size=8, neuron=lang.CUBA_LIF(tau_mem=20 * lang.ms)
        )
        adaptive = net.population(
            "adaptive",
            size=8,
            neuron=lang.CustomNeuron(
                "example.adaptive_lif/v1",
                tau_mem_ms=20,
                tau_adapt_ms=100,
                adaptation_na=0.35,
            ),
        )
        weights = net.parameter(
            "weights",
            shape=(8, 4),
            unit="nA",
            initializer=lang.CustomInitializer(
                "example.clipped_normal/v1", mean=5.0, std=1.0, minimum=0.0
            ),
            constraint=lang.NonNegative(),
        )
        for cells in (standard, adaptive):
            projection = net.connect(
                inputs,
                cells.excitatory,
                name=f"input_to_{cells.id}",
                synapse=lang.CustomSynapse(
                    "example.exponential_current/v1", tau_ms=5.0
                ),
                weight=weights,
            )
            net.output(f"{cells.id}_spikes", cells.spikes)
            net.expose(cells.voltage, name=f"{cells.id}_voltage")
            net.expose(projection.current, name=f"{cells.id}_current")
        net.expose(inputs, name="input_spikes")
        net.expose(adaptive.state("adaptation"), name="adaptation")

        bundle = lang.compile(net, target="tools/snnsim")
        bundle.write(bundle_path)

    # 6. Compile and execute: the bundle stores names/config, not Python code.
    bundle = lang.load_bundle(bundle_path)
    viz.render_diagram(
        lang.diagram(bundle, view="expanded"),
        OUTPUT_DIR / "network.png",
        scale=2,
        height_to_width_ratio=None,
        canvas_size=(1920, 900),
    )
    result = simulate(
        bundle=bundle_path,
        input_bindings=(binding,),
        seed=SEED,
        device=args.device,
        performance=Performance(compile_mode=None if args.eager else "default"),
        extension_validation=args.extension_validation,
    )
    (OUTPUT_DIR / "metrics.json").write_text(
        json.dumps(result.metrics, indent=2, allow_nan=False) + "\n"
    )
    data = result.numpy(batch=0)
    assert data.time_ms is not None

    # 7. Plot the same stimulus, both responses and the custom adaptation state.
    import matplotlib.pyplot as plt

    layout = viz.FigureGrid(
        rows=4, columns=1, row_gap=0.035, bounds=(0.14, 0.07, 0.82, 0.86)
    )
    for index, name in enumerate(("inputs", "spikes", "voltage", "adaptation")):
        layout.place(name, row=index, column=0)
    figure = layout.figure(figsize=(11, 11))
    axes = [layout.add_axes(figure, "inputs")]
    for name in ("spikes", "voltage", "adaptation"):
        axes.append(layout.add_axes(figure, name, sharex=axes[0]))
    for channel in range(4):
        axes[0].plot(
            data.time_ms[data.diagnostics["input_spikes"][:, channel] > 0],
            np.full(int(data.diagnostics["input_spikes"][:, channel].sum()), channel),
            "|",
            color=viz.Theme().ink,
        )
    axes[0].set_ylabel("Input channel")
    for prefix, offset, color in (
        ("standard", 0, viz.Theme().ink),
        ("adaptive", 9, viz.Theme().accent),
    ):
        spikes = data.outputs[f"{prefix}_spikes"]
        for cell in range(8):
            times = data.time_ms[spikes[:, cell] > 0]
            axes[1].plot(times, np.full(len(times), cell + offset), "|", color=color)
        axes[2].plot(
            data.time_ms,
            data.diagnostics[f"{prefix}_voltage"][:, 0],
            color=color,
            label=prefix,
        )
    axes[1].set_ylabel("Cell")
    axes[1].set_yticks([3.5, 12.5], ["Standard", "Adaptive"])
    axes[2].set_ylabel("Voltage (mV)")
    axes[2].legend(loc="upper right")
    axes[3].plot(
        data.time_ms, data.diagnostics["adaptation"][:, 0], color=viz.Theme().accent
    )
    axes[3].set_ylabel("Adaptation (nA)")
    axes[3].set_xlabel("Time (ms)")
    for axis in axes:
        axis.axvspan(100, 400, color=viz.Theme().rule, alpha=0.5, zorder=-1)
        axis.set_xlim(0, DURATION_MS)
    for axis in axes[:-1]:
        axis.tick_params(labelbottom=False)
    figure.savefig(OUTPUT_DIR / "customisation.png", dpi=160)
    plt.close(figure)
    for prefix in ("standard", "adaptive"):
        print(f"{prefix}: {int(data.outputs[f'{prefix}_spikes'].sum())} spikes")
    print(f"Saved {OUTPUT_DIR / 'customisation.png'}")


if __name__ == "__main__":
    main()
```
