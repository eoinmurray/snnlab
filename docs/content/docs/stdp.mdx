---
title: Spike-Timing-Dependent Plasticity
description: Learn input weights with pair-based STDP in a conductance-based neuron, after Song, Miller and Abbott (2000).
---

One conductance-based LIF neuron receives 1000 excitatory and 200 inhibitory Poisson inputs. Its excitatory synapses learn with [`stdp_simple`](/api/lang#plasticity): pair-based, additive spike-timing-dependent plasticity with hard bounds. A synapse strengthens when its input spike precedes an output spike and weakens when it follows one.

The setting follows [Song, Miller and Abbott (2000)](https://doi.org/10.1038/78829). Their study made two points. First, STDP regulates the neuron's output rate: stronger input does not simply produce proportionally more output. Second, STDP makes inputs compete: inputs that fire together win, and the others weaken. This example tests both claims in 100 seconds of simulated time.

Three experiments run side by side, as three trials of one batch:

1. 10 Hz inputs, all independent;
2. 10 Hz inputs, with the first half correlated;
3. 20 Hz inputs, all independent.

Each trial learns its own copy of the weights, and all three start from the same initial weights. The comparison is therefore controlled: only the input statistics differ.

![1000 excitatory inputs reach one COBA LIF neuron through plastic AMPA synapses; 200 inhibitory inputs reach it through static GABA synapses.](/stdp/network.png)

## Run the example

Run from the repository root:

```bash
uv run python examples/stdp/example.py
uv run pytest tests/sim/test_stdp_example.py -q
```

The run takes between half a minute and a minute and a half on a CPU, depending on the machine. It replaces `results/` with `network.png`, `stdp-window.png`, `stdp-learning.png` and `summary.json`. The summary records the measured rates, the weight statistics and a SHA-256 hash of the final weights. The same seed on the same machine reproduces it exactly. On another machine, float32 rounding can move a spike by one step, and the run then differs in detail; the conclusions below do not depend on such details. Graphviz's `dot` command is required for the diagram.

## 1. Parameters

```python
DT_MS = 0.5
STEPS_PER_SECOND = round(1000 / DT_MS)
LEARNING_SECONDS = 100
PROBE_SECONDS = 5
N_EXC = 1000
N_INH = 200
INH_RATE_HZ = 10.0
W_MAX_US = 0.001
W_INH_US = 0.002
A_PLUS_US = 0.02 * W_MAX_US
A_MINUS_US = 1.05 * A_PLUS_US
TAU_MS = 20.0
SEED = 7

# One trial per experiment: label, excitatory input rate (Hz) and the correlation
# within the first half of the excitatory inputs.
EXPERIMENTS = (
    ("10 Hz, independent", 10.0, 0.0),
    ("10 Hz, half correlated", 10.0, 0.2),
    ("20 Hz, independent", 20.0, 0.0),
)
```

Weights are conductances in µS. The bound `W_MAX_US = 0.001` is 1 nS, which is 2% of the neuron's leak conductance (1 nF / 20 ms = 50 nS). One synapse alone is weak; the neuron fires only when many inputs act together.

The amplitudes are absolute, in µS. Potentiation adds up to 2% of `w_max` per spike pair. Depression is 5% stronger, the ratio Song et al. used. That small excess makes uncorrelated pairings depress on balance, which drives the rate regulation below. The amplitude is larger than in the original study, so learning settles within 100 seconds; the price is noisier weights.

## 3. The neuron and its plastic synapses

```python
cell = net.population(
    "neuron",
    size=1,
    neuron=lang.COBA_LIF(tau_mem=20 * lang.ms),
)
net.connect(
    exc,
    cell.excitatory,
    name="exc_to_neuron",
    synapse=lang.AMPA(tau=5 * lang.ms),
    weight=lang.Uniform(
        0.0,
        W_MAX_US,
    ),
    initialization_scaling="direct",
    plasticity=lang.STDPSimple(
        a_plus=A_PLUS_US,
        a_minus=A_MINUS_US,
        tau_plus=TAU_MS * lang.ms,
        tau_minus=TAU_MS * lang.ms,
        w_max=W_MAX_US,
        pairing="all_to_all",
    ),
)
net.connect(
    inh,
    cell.inhibitory,
    name="inh_to_neuron",
    synapse=lang.GABA(tau=5 * lang.ms),
    weight=lang.Constant(W_INH_US),
    initialization_scaling="direct",
)
```

`plasticity=lang.STDPSimple(...)` is the only difference from a static projection. The rule needs a spiking source, a spiking target and an excitatory receptor; see [supported projections](/api/lang#supported-projections). The inhibitory projection stays static. `stdp_simple` rejects inhibitory receptors with `E121`, because inhibitory plasticity needs a different rule.

[COBA_LIF](/api/extensions#neuron-models) uses a 20 ms membrane time constant and a −50 mV threshold. Its excitatory reversal potential is 0 mV and its inhibitory one −80 mV, so AMPA input depolarizes the cell and GABA input pulls it below rest. `initialization_scaling="direct"` keeps the drawn weights in µS, without fan-in normalization. Initial weights are uniform between 0 and `w_max`.

`pairing="all_to_all"` lets every spike pair with every earlier spike on the other side, as in the original model. The update step section of [Plasticity](/api/lang#the-update) gives the exact discrete-time conventions.

## 4. Correlated and independent spike trains

```python
def input_chunk(rng):
    """One second of Poisson spikes for every experiment, as (time, batch, inputs)."""
    p_inh = INH_RATE_HZ * DT_MS / 1000
    exc = np.empty((STEPS_PER_SECOND, len(EXPERIMENTS), N_EXC), dtype=bool)
    for trial, (_, rate_hz, correlation) in enumerate(EXPERIMENTS):
        p = rate_hz * DT_MS / 1000
        exc[:, trial] = rng.random((STEPS_PER_SECOND, N_EXC)) < p
        if correlation > 0:
            # Each input of the first half keeps its own spikes at rate (1 - c)·r
            # and copies a shared train at rate c·r.
            own = rng.random((STEPS_PER_SECOND, GROUP)) < (1 - correlation) * p
            shared = rng.random((STEPS_PER_SECOND, 1)) < correlation * p
            exc[:, trial, :GROUP] = own | shared
    inh = rng.random((STEPS_PER_SECOND, len(EXPERIMENTS), N_INH)) < p_inh
    return {
        "exc": torch.from_numpy(exc).float(),
        "inh": torch.from_numpy(inh).float(),
    }
```

All excitatory inputs of one experiment fire at the same rate. In the correlated half, each input keeps independent spikes at rate (1 − c)·r and copies a shared train at rate c·r. Two inputs of that half then share about a fraction c of their spikes. Correlation changes timing, not rate. Any difference between the experiments' learned weights therefore comes from spike timing.

## 5. Build the model

```python
bundle = lang.compile(
    build_network(),
    target="tools/snnsim",
)
model = GraphExecutor(
    plan_graph(bundle.graph),
    seed=SEED,
)
```

The executor is built once and reused for every chunk. Its weights are the starting point of every trial, and runs never change them. Learned weights live in each result and in its runtime state.

## 6. Learn in one-second chunks

```python
def learn(model, rng, seconds):
    recording = RecordingSpec(
        signals=(
            SignalRecording(
                "exc_to_neuron.weight",
                every_steps=STEPS_PER_SECOND,
            ),
        ),
    )
    state = None
    rates, snapshots = [], []
    for _ in range(seconds):
        result = model(
            input_chunk(rng),
            runtime_state=state,
            recording=recording,
            diagnostics=False,
        )
        state = result.runtime_state
        rates.append(result.outputs["spikes"].sum(dim=0)[:, 0])
        snapshots.append(result.recorded_signals["exc_to_neuron.weight"][-1, :, :, 0])
    final = result.parameters["exc_to_neuron.weight"][:, :, 0]
    return state, torch.stack(rates), torch.stack(snapshots), final
```

Each call simulates one second. `runtime_state` carries the learned weights, both traces and the neuron's state into the next call. A chunked run is therefore identical to one long run; one-second chunks keep the input tensors small.

`SignalRecording(..., every_steps=STEPS_PER_SECOND)` records the weights once per second, after the last step of each chunk. The recorded signal has axes `(time, batch, source, target)`; `[-1, :, :, 0]` takes the last snapshot, every trial, every input and the one neuron. `result.parameters` holds the final weights per trial with the same `(batch, source, target)` layout. See [Recording weights and traces](/api/sim#recording-weights-and-traces).

## 7. Measure with learning frozen

```python
def probe(model, rng, state, seconds):
    spikes = 0
    for _ in range(seconds):
        result = model(
            input_chunk(rng),
            runtime_state=state,
            learning=False,
            diagnostics=False,
        )
        state = result.runtime_state
        spikes = spikes + result.outputs["spikes"].sum(dim=0)[:, 0]
    return spikes / seconds
```

`learning=False` runs the plastic projection with its current weights and does not change them. Without a state, the probe uses the initial weights; with the learned state, it uses the learned ones. Both probes see fresh inputs with the same statistics. The rates before and after learning are therefore directly comparable.

`run_example` runs the first probe, the learning phase and the second probe in order, on one random stream:

```python
rng = np.random.default_rng(SEED)

rate_before = probe(model, rng, None, probe_seconds)
state, rates, snapshots, final = learn(model, rng, learning_seconds)
rate_after = probe(model, rng, state, probe_seconds)
```

## 8. The learning window

```python
def learning_window(max_lag_ms=100):
    rule = stdp_simple.STDPSimple(
        a_plus=A_PLUS_US,
        a_minus=A_MINUS_US,
        tau_plus_ms=TAU_MS,
        tau_minus_ms=TAU_MS,
        w_max=W_MAX_US,
        pairing="all_to_all",
    )
    max_lag = round(max_lag_ms / DT_MS)
    lags = np.arange(-max_lag, max_lag + 1, 4)
    # One trial per lag: a presynaptic spike at `start` and a postsynaptic spike
    # `lag` steps later.
    start = max_lag + 1
    pre = torch.zeros(2 * max_lag + 3, len(lags), 1, dtype=torch.float64)
    post = torch.zeros_like(pre)
    pre[start, :, 0] = 1
    post[start + lags, np.arange(len(lags)), 0] = 1
    w0 = torch.full((len(lags), 1, 1), W_MAX_US / 2, dtype=torch.float64)
    weights = w0
    state = stdp_simple.init_state(
        rule,
        batch=len(lags),
        n_source=1,
        n_target=1,
    )
    for pre_t, post_t in zip(pre, post, strict=True):
        weights, state = stdp_simple.step(
            rule,
            state,
            weights,
            pre_t,
            post_t,
            dt_ms=DT_MS,
        )
    return lags * DT_MS, (weights - w0).flatten().numpy()
```

The pure update step, `snnlab.sim.plasticity.stdp_simple.step`, runs the rule on fixed spike trains, without a network. Here each trial holds one spike pair at a different lag. The result is the classic STDP window: potentiation when the input spike comes first, depression when it comes second.

![Weight change for one spike pair against the lag between the postsynaptic and the presynaptic spike, computed with the update step and compared with the exponential formula.](/stdp/stdp-window.png)

Every point lies on the formula. The pair at lag zero produces no change, because spikes in the same step do not pair. See [The update step](/api/sim#the-update-step).

## 9. Results

![Four panels: output rate during learning for the three experiments; mean weights recorded every second; final weight of each input in the half-correlated experiment; final weight distributions.](/stdp/stdp-learning.png)

| Experiment | Output rate before (Hz) | Output rate after (Hz) | Mean weight, inputs 0–499 | Mean weight, inputs 500–999 | Below 0.1 | Above 0.9 |
| --- | --- | --- | --- | --- | --- | --- |
| 10 Hz, independent | 17.0 | 10.2 | 0.47 | 0.49 | 17% | 14% |
| 10 Hz, half correlated | 11.4 | 26.4 | 0.98 | 0.27 | 17% | 51% |
| 20 Hz, independent | 93.0 | 18.4 | 0.26 | 0.26 | 38% | 3% |

The output rates come from the frozen probes before and after learning. Weights are fractions of `w_max`.

**STDP regulates the output rate.** Before learning, doubling the input rate multiplies the output rate several times. After learning, the gap between the two independent experiments is far smaller. Depression is slightly stronger than potentiation, so random pairings weaken the synapses. The more the neuron fires, the more random pairings occur. Weights fall until the output rate settles.

**Correlated inputs win the competition.** In the half-correlated experiment, the correlated inputs rise to the upper bound. The independent inputs of the same neuron fall well below their starting mean. Shared spikes often trigger an output spike shortly after they arrive. These causal pairings potentiate the correlated synapses. The independent inputs see mostly random pairings and lose. In the fully independent 10 Hz experiment, the mean weight barely moves. The difference between the two experiments is therefore timing, not rate.

**The distributions spread towards the bounds.** The initial weights are uniform. After learning, the half-correlated experiment splits into two groups, and the 20 Hz experiment collects near zero. In the independent 10 Hz experiment the distribution has begun to move towards both bounds. Song et al. reported a fully bimodal distribution; that takes longer than this run.

The half-correlated neuron ends with a higher output rate than the independent 10 Hz neuron. Its strongest inputs fire together, so their combined effect is large.

Try a different `EXPERIMENTS` list, a larger correlation or `pairing="nearest"`, and compare the summary.

    return net

    spikes = 0
    for _ in range(seconds):
        result = model(
            input_chunk(rng),
            runtime_state=state,
            learning=False,
            diagnostics=False,
        )
        state = result.runtime_state
        spikes = spikes + result.outputs["spikes"].sum(dim=0)[:, 0]
    return spikes / seconds

def run_example(learning_seconds=LEARNING_SECONDS, probe_seconds=PROBE_SECONDS):
    bundle = lang.compile(
        build_network(),
        target="tools/snnsim",
    )
    model = GraphExecutor(
        plan_graph(bundle.graph),
        seed=SEED,
    )
    initial = model.parameter_map()["exc_to_neuron.weight"].detach().flatten()
    rng = np.random.default_rng(SEED)

    rate_before = probe(model, rng, None, probe_seconds)
    state, rates, snapshots, final = learn(model, rng, learning_seconds)
    rate_after = probe(model, rng, state, probe_seconds)

    return {
        "bundle": bundle,
        "initial": initial.numpy(),
        "rates": rates.numpy(),
        "snapshots": snapshots.numpy(),
        "final": final.numpy(),
        "rate_before": rate_before.numpy(),
        "rate_after": rate_after.numpy(),
        "window": learning_window(),
    }


def summarise(run):
    final = run["final"] / W_MAX_US
    experiments = []
    for trial, (label, rate_hz, correlation) in enumerate(EXPERIMENTS):
        experiments.append(
            {
                "label": label,
                "input_rate_hz": rate_hz,
                "correlation_first_half": correlation,
                "output_rate_before_hz": round(float(run["rate_before"][trial]), 2),
                "output_rate_after_hz": round(float(run["rate_after"][trial]), 2),
                "mean_weight_first_half": round(float(final[trial, :GROUP].mean()), 4),
                "mean_weight_second_half": round(float(final[trial, GROUP:].mean()), 4),
                "fraction_below_0.1": round(float(np.mean(final[trial] < 0.1)), 4),
                "fraction_above_0.9": round(float(np.mean(final[trial] > 0.9)), 4),
            }
        )
    return {
        "learning_seconds": len(run["rates"]),
        "seed": SEED,
        "weights_relative_to": "w_max",
        "experiments": experiments,
        "final_weights_sha256": hashlib.sha256(run["final"].tobytes()).hexdigest(),
    }


def plot_window(window):
    lags_ms, change = window
    analytic_ms = np.linspace(lags_ms[0], lags_ms[-1], 801)
    analytic = np.where(
        analytic_ms > 0,
        A_PLUS_US * np.exp(-analytic_ms / TAU_MS),
        -A_MINUS_US * np.exp(analytic_ms / TAU_MS),
    )
    figure, axis = plt.subplots(
        figsize=(7, 3.6),
        dpi=150,
        layout="constrained",
    )
    axis.axhline(
        0,
        color=MUTED,
        linewidth=0.8,
    )
    axis.axvline(
        0,
        color=MUTED,
        linewidth=0.8,
    )
    for side in (analytic_ms < 0, analytic_ms > 0):
        axis.plot(
            analytic_ms[side],
            analytic[side] / W_MAX_US,
            color=MUTED,
            linewidth=3,
            label="Formula" if side[-1] else None,
        )
    axis.scatter(
        lags_ms,
        change / W_MAX_US,
        s=12,
        color=COLORS[0],
        zorder=3,
        label="Update step, one spike pair",
    )
    axis.annotate(
        "same step: no pairing",
        xy=(0, 0),
        xytext=(12, -0.008),
        color=INK,
        arrowprops={"arrowstyle": "-", "color": MUTED},
    )
    axis.set_xlabel("Lag t_post − t_pre (ms)")
    axis.set_ylabel("Weight change (× w_max)")
    axis.set_title(
        "Learning window",
        pad=10,
    )
    axis.legend(frameon=False)
    figure.savefig(OUTPUT_DIR / "stdp-window.png")
    plt.close(figure)


def plot_learning(run):
    rates = run["rates"]
    snapshots = run["snapshots"] / W_MAX_US
    final = run["final"] / W_MAX_US

    figure, axes = plt.subplots(
        2,
        2,
        figsize=(11, 7.5),

    rate_axis.set_title(
        f"Output rate during learning ({window} s running mean)",
        pad=10,
    )
    rate_axis.set_ylim(bottom=0)
    rate_axis.legend(frameon=False)
